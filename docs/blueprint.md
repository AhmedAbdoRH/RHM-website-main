# **App Name**: RHM Digital Prestige

## Core Features:

- Scroll-triggered animations: Implement animations that trigger as users scroll, dynamically loading content and creating an engaging experience.
- Micro-interaction enhancements: Subtle visual feedback on interactive elements such as buttons and links.
- AI-powered lead qualification chatbot: An intelligent chatbot that guides potential B2B leads to the right team using qualifying questions to determine their specific needs such as 'Technical Solutions' or 'Creative Production'. This chatbot is a tool for initial contact.
- Enhanced Portfolio Filtering: Implement a filtering system on the portfolio page, allowing users to sort projects by 'Tech/Web Dev', 'Video/Media Production', and 'Branding/Graphics' categories.

## Style Guidelines:

- Primary color gradient: Light Lime Green (#cdf1ad) to Deep Teal (#62ae90) for backgrounds and buttons, representing freshness, growth, technical depth, and professionalism.
- Text color: Pure White (#ffffff) for headings and text on colored backgrounds.
- Text color: Dark Olive Green (#1e331e) for headings and text on white backgrounds, offering a sophisticated alternative to pure black.
- Headline font: 'Poppins', a geometric sans-serif, for a modern and fashionable look.
- Body font: 'PT Sans', a humanist sans-serif, ensuring readability and a blend of modern and warm aesthetics.
- Subtle fade-in animations for content blocks as they scroll into view.
- Sleek underline animation for navigation links on hover.
